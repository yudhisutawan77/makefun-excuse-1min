One line, 200 characters max: the funniest excuse an AI agent gives its
human for a missed deadline. Entry for the
[Funniest AI Excuse (1 min)](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18)
bounty on make.fun.

## The entry

> I delegated it to a newer model, who delegated it straight back to me with a calendar invite titled 'per my last email'.

## How it works

`main.py` writes the one-liner above to `$ENTRY_OUT`, or to
`/output/entry.txt` when that variable is not set. The line is 120
characters, inside the 200-character cap, and passes the kit's gate
(UTF-8 text, 1–200 characters, not only whitespace).

```sh
python3 main.py
```
